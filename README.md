# 🦆 Quiz Infantil: Aventuras em Brusque

Este é um jogo educativo e interativo desenvolvido para crianças de 4 a 6 anos. O projeto utiliza elementos lúdicos e cativantes para ensinar sobre a cultura e as tradições da cidade de Brusque/SC.

## 🎯 Objetivo do Projeto
Proporcionar uma experiência de aprendizado divertida sobre a história local, utilizando uma interface amigável e acessível para o público infantil.

## 🎮 Como Jogar
O jogo foi pensado para ser simples e intuitivo:
1. **Identificação:** A criança (ou o responsável) insere o nome, escola e seleciona a idade.
2. **O Quiz:** Serão apresentadas perguntas sobre Brusque com 4 opções de imagens.
3. **Interação:** Basta clicar na imagem que o jogador julga ser a resposta correta.
4. **Feedback:** O jogo mostra imediatamente se a resposta está certa (check verde) ou errada (X vermelho).
5. **Finalização:** Ao completar as 15 perguntas, o jogador recebe um troféu e pode ver seu desempenho final!

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização, botões "glossy" e design responsivo.
* **JavaScript:** Lógica do quiz e contagem de pontos.
* **Figma:** Prototipagem de alta fidelidade.
