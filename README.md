# 🦆 Quiz Infantil: Aventuras em Brusque

Este é um jogo educativo e interativo desenvolvido para crianças de 4 a 6 anos. O projeto utiliza elementos cativantes para ensinar sobre a cultura e as tradições de Brusque/SC.

## 🎯 Objetivo do Projeto
Proporcionar uma experiência de aprendizado divertida sobre a história local, utilizando uma interface amigável e acessível para o público infantil, focando em reconhecimento visual e interação intuitiva.

## 🎮 Funcionalidades e Experiência do Usuário
1. **Identificação:** A criança insere o nome, escola e seleciona a idade em uma interface temática.
2. **Interface Fullscreen:** O cenário do parque e as telas de quiz ocupam 100% da tela do navegador, eliminando distrações externas.
3. **Barra de Progresso Dinâmica:** Um sistema visual que mostra o caminho percorrido até o troféu final.
4. **Feedback Imediato:** Respostas corretas e incorretas são acompanhadas de ícones visuais (Verde/Vermelho).
5. **Troféu Animado:** O grande prêmio final possui animação de comemoração (pulso e rotação) para celebrar a vitória da criança.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** - Estilização avançada com `Flexbox`.
    - Animações com `@keyframes`.
    - Efeitos de `Blur` e `Backdrop-filter`.
    - Design responsivo com unidades `vw` e `vh`.
* **JavaScript (ES6+):** Lógica do quiz, manipulação dinâmica do DOM e gerenciamento de estados das telas.
* **Figma:** Prototipagem de alta fidelidade e design de assets.
